# Security Policy

If you believe you've found a security vulnerability in Zappigo, please
**do not** open a public GitHub issue.

## Reporting

Email **kim@wisell.ai** with:

- A description of the issue and its potential impact.
- Steps to reproduce (a minimal repro is ideal).
- Anything else that would help us understand and fix it quickly.

We'll acknowledge your report, work on a fix, and credit you (if you'd like)
once it's resolved. Please give us a reasonable time to address the issue
before any public disclosure.

## Scope

This is a self-hosted application — if you're running your own deployment,
you're responsible for your own cloud credentials, secrets and
infrastructure hardening (see [infra/README.md](infra/README.md)). Reports
about the application code itself (auth, multi-tenant isolation, the bot's
guardrails, injection, etc.) are very much in scope and appreciated.
